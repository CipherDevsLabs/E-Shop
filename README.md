
# 🛍️ E-Shop – Modern E-Commerce Frontend

[![React](https://img.shields.io/badge/React-19-blue?style=flat-square\&logo=react)](https://react.dev/)
[![Vite](https://img.shields.io/badge/Vite-7-purple?style=flat-square\&logo=vite)](https://vitejs.dev/)
[![Redux Toolkit](https://img.shields.io/badge/Redux%20Toolkit-2.9-purple?style=flat-square\&logo=redux)](https://redux-toolkit.js.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind%20CSS-v4-blue?style=flat-square\&logo=tailwind-css)](https://tailwindcss.com/)
[![Deployment](https://img.shields.io/badge/Deployment-Vercel-black?style=flat-square\&logo=vercel)](https://vercel.com/)

**E-Shop** is a modern, fast, and fully responsive e-commerce frontend application built with the latest React ecosystem.
It provides a smooth shopping experience with state management, routing, and a clean UI powered by Tailwind CSS.

🌐 **Live Demo:**
👉 [https://e-shop-nine-tawny.vercel.app/](https://e-shop-nine-tawny.vercel.app/)

---

## 🌟 Features

### 🛍️ Shopping Experience

* Browse products with modern UI
* Add products to cart 🛒
* Increase / decrease product quantity
* Remove items from cart ❌
* Real-time cart updates using global state

### 🔔 Notifications

* Beautiful toast notifications powered by React Hot Toast
* Instant user feedback on cart actions

### ⚡ Performance & UX

* Lightning-fast development & builds with Vite
* Client-side routing with React Router
* Fully responsive design (Mobile, Tablet, Desktop) 📱💻
* Clean and scalable architecture

## 🚀 Getting Started

### Prerequisites

* Node.js 18+

### Installation

```bash
# Clone the repository
git clone [https://github.com/CipherDevsLabs/E-Shop]
cd ecommerce-frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Open:

```
http://localhost:5173
```
